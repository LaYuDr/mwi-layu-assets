# 资产助手

为《银河奶牛放置》（Milky Way Idle）按游戏原生市场价格估算资产，保存历史、分项变化和本地备份。安装后刷新游戏，在侧栏打开「资产助手」。

[从 Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/600009)

## 主要功能

- **库存与装备估值**：按物品和强化等级估算库存、身上装备及金币价值。
- **订单资产**：汇总订单剩余物品、真实冻结金币与待领取资产。
- **房屋重建价值**：按当前材料价格估算从零建到当前等级的全部材料与金币成本。
- **历史与分项变化**：查看已保存的资产历史、每日变化、物品及房屋明细。
- **本地备份**：导出当前角色资产记录，校验后合并导入；不同服务器和角色分别保存。

价格来自游戏官方原生行情，不采用挂单买价、卖价或第三方报价。缺价及不可交易资产显示为未估值，已估值小计不代表完整总额；房屋价值是重建成本，资产变化不等于已实现利润。历史从实际观察开始，不补造离线过程。

插件不会自动交易、强化、升级或发送聊天，不读取登录凭据，不上传玩家资产。资产记录与备份保存在本地，不发送至统计服务。

## 安装与活跃统计及隐私

资产助手的安装与活跃统计默认关闭，可在游戏内「资产助手 → 数据保存、同步与备份 → 安装与活跃统计」阅读说明并确认开启，也可随时关闭，不影响插件功能。

- 开启时仅向柆雨的统计服务发送插件标识、版本和随机安装标识的 SHA-256 摘要，用于统计安装数与每日活跃安装数，不统计游戏内操作。
- 不使用硬件指纹，不发送账号、角色、聊天、资产、交易或 Cookie。安装标识仅保存在该脚本的 Tampermonkey 存储中；摘要用于识别同一安装。请求通过 HTTPS 发送。
- 关闭后不再上报，已有历史保留。

完整说明与源码见 [GitHub 项目](https://github.com/LaYuDr/mwi-layu-assets)。
