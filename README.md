# 银河奶牛资产助手

[从 GitHub 安装正式版](https://raw.githubusercontent.com/LaYuDr/mwi-layu-assets/main/mwi-layu-assets.user.js)。Greasy Fork 入口尚在配置。

在 Milky Way Idle 游戏侧栏添加独立“资产”页签，以游戏原生市场价格统计资产，所有数据留在浏览器本地。

- 库存和身上装备，按物品和强化等级精确估值。
- 订单剩余物品、真实冻结金币和待领取资产。
- 房屋从零到当前等级累计所有材料和金币，以当前价格计算重建价值。
- 总资产历史、每日变化、各分项及物品变化，支持日期范围和基期比较。
- 本地备份导出与校验后合并导入。

安装 Tampermonkey 后安装脚本，刷新游戏可见“资产”。国服、国际服及测试服各自保存；同一浏览器、同一游戏地址可直接读取此前强化助手的资产历史。切换时更新原强化助手并刷新，避免旧入口重复；开发版与正式版只启用一个。

价格来自游戏官方原生 market_values.json，不采用挂单买价、卖价或第三方行情。缺价与不可交易资产显示未估值；已估值小计不冒充完整总额。房屋是重建成本，资产变化也不等于已实现利润。历史只从实际观察开始，不补造离线数据。

不会自动执行交易、强化、升级或聊天，不上传玩家资产。不同域名、设备、浏览器间迁移请使用本地备份；卸载脚本不要清除游戏站点数据。
